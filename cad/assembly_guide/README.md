# 87项器材讲解与装配图解

> 历史资料：2026-11-03 已将用户指定的 2026-10-13 ZIP 设为当前模型。本目录的网格、图片、PDF 和验证记录仍对应 [6ad9346 中的后续修订模型](https://github.com/A123536/final-report/tree/6ad93463daccba81145dd6c9fa55dd463d4a2adb/cad/solidworks/model)，不代表当前选定版；下文重建工具也未随版本选择回退。

先打开本目录的《V型管道机器人_87项器材讲解与装配图解_2026-10-28.pdf》。前8张图分别解释整机位置、传动、外壳、中心弹簧机构、供电、控制、视觉和拖线；第09/10节列装配上电顺序和功能端口；后续按采购编号解释全部87项。

采购 `E01` 是运动主控板，外壳图号 `E-01` 是电源舱上盖。它们不是同一套编号。

每项均说明作用、放置位置、连接对象及装配要点。并不是87项都要安装在机器人上：调试器、工具和备件放在管外；未冻结的制造件仍需出图。

## 图示文件

- `01-overall-model`：原生网格整机分区。
- `02-drive-train`：25T电机齿轮—25T惰轮—40T轮轴齿轮与轴承支撑。
- `03-enclosure-exploded`：六件PETG电子外壳拆分和紧固关系。
- `04-v-linkage`：三轮压壁、镜像扭簧、机械限位与锁销。
- `05-power-tree`：24V/12V/5V供电与保险/急停分支。
- `06-control-rs485`：运动命令、驱动、电流/故障反馈与编码器。
- `07-vision-path`：CSI相机—Luckfox—以太网—电脑与白光补光。
- `08-tether-bundle`：电源、以太网、RS485和独立回收绳。

同名PNG便于查看、插入报告；SVG便于放大。图形来自项目网格及自行绘制的技术示意，没有生成AI外观图来替代真实装配。

## 使用边界

网格源为Rev C的50种零件、127个组件，原生CAD只读导出前后 `SaveFlag=False`，没有保存回CAD。轮子、电机、齿轮、弹簧和板卡含原有包络，不能把显示三角网格当作实物孔位或制造图。

新增Luckfox、实际5V降压、机架夹持座及三路拖线入口尚未在旧CAD中定版。尤其是E-05/E-06相机舱，应按新视觉硬件和接头/弯线空间实测改图，不能直接套用旧STL。

接线图标的是功能端口。F411具体GPIO、六芯电机插头线序、载板布线、供电反灌隔离及保护参数均需最终电路图和台架测试确认。不能只看线色接线。

## 重建

`ExportAssemblyExplainerMesh.cs` 通过SOLIDWORKS API只读导出显示网格到 `native_scene.json`；只关闭由工具自身打开的文档/实例，不覆盖原装配。

`build_assembly_guide.py` 使用采购JSON及87项解释JSON，生成图示、PDF与Markdown。`build_inline_explainer.py` 将字面模板、相同网格及器材编号数据组合成对话中的交互模型；对话源文件位于本聊天专属可视化目录，不是制造交付物。
