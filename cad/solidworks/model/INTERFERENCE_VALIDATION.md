# SOLIDWORKS 修订装配干涉与状态验证

## 修订原因

首版概念装配报告 246 处实体相交。除轴、轴承和紧固连接外，主要问题是设备舱被画成实心块、φ60全向轮被画成整圆盘、直接25T/40T传动使φ37齿轮箱侵入轮子包络，以及线束使用直线段穿过电机和板卡。

## 结构修订

- 全向轮改为φ26轮芯、φ18/φ8轮毂、6根薄辐条和12个滚子包络，整体接触包络仍为φ60×28 mm。
- 增加25T惰轮：25T电机齿轮—25T惰轮中心距25.0 mm，惰轮—40T轮轴齿轮中心距32.5 mm；电机轴距轮轴57.5 mm，总减速比仍为1.6。
- 惰轮使用φ6轴及686（6×13×5 mm）轴承包络；三根主轴统一使用619/8（8×19×6 mm）轴承包络。
- 设备舱先由实心块改成开口罩，本轮进一步改为72×62×22 mm上盖及2.4 mm底板；含侧螺柱总宽69 mm，六件式 PETG 拼接详见 `../../../design/printable_enclosure_joint_plan.md`。
- 连杆双侧轨道移至Y=±43 mm；中心轴修正为φ8 mm；轴承、扭簧、限位片和40 mm快拔销分层布置。
- 电源线和信号线分别走Y=-37 mm和Y=+36.5 mm通道，在中心关节降低高度，并绕开前电机与主动轮后进入相机舱的两处9×12 mm过线开口。

## 实体干涉检查

使用 SOLIDWORKS InterferenceDetectionManager，关闭“重合视为干涉”，检查全部实体组件，包括默认隐藏的管道。以下为本轮最终外壳、布线及端子位置的重新检查结果；端点姿态沿用已生成的机构变换，替换为相同最终外壳实体后复查。

| 管径姿态 | 报告项 | 非预期干涉 | 结果 |
|---:|---:|---:|---|
| 140 mm | 23 | 0 | 通过 |
| 150 mm | 23 | 0 | 通过 |
| 160 mm | 23 | 0 | 通过 |

最终23项均属于概念连接包络和线段端点接合：

- 2项限位片与连杆轨道连接；
- 1项格兰头与外部拖线连接；
- 4项齿轮啮合包络；
- 2项快拔销与轨道/限位片连接；
- 2项电源线与格兰头/拖线入口连接；
- 12项相邻线束段端点连接。

原先两项相机舱入口实体穿透已由真实过线槽消除。六件外壳的独立合盖装配报告0项实体干涉；在140、150、160 mm三种整机姿态中，另用12只螺钉的螺杆和头部实体包络逐一检查，均为0项碰撞。设备舱必须使用头径≤5.7 mm、头高≤1.7 mm的M3×10低圆头螺钉；普通高圆柱头曾与两端编码器干涉，已从采购要求中排除。

逐项原始记录位于 `printable_enclosure/INTERFERENCE_ID*.txt`、`FASTENER_CLEARANCE_ID*.txt` 及 `INTERFERENCE_CLOSED_ENCLOSURE.txt`。

滚子中心已修正到Y=±10 mm，8 mm宽滚子的总外廓严格位于±14 mm内。保险端子最终位置为电源舱局部 X=30、Y=39、Z=-12 mm，兼顾线束和最小管径的管壁空间。

686（6×13×5 mm）惰轮轴承和619/8（8×19×6 mm）主轴承均已包含在本轮三种姿态的最终检查中。

## 打印实体与文件检查

六件打印零件均为单个实体，SOLIDWORKS `Check3` 未报告几何错误；上盖和底板共16个M3孔以圆柱探针验证贯通。STL均为单个连通封闭网格、法向一致、毫米尺度正确，最低Z=0，已摆放为建议打印方向。A3分件图包含7页，PDF渲染逐页复核，无文字和视图重叠。原始记录见 `PRINT_PART_GEOMETRY_AUDIT.txt` 和 `STL_VALIDATION.json`。

## 受力与牵引模型复核

修订没有改变轮径、150 mm连杆轴距、弹簧参数、目标质量上限或总传动比。新增惰轮带来两次外啮合，仿真继续采用两次啮合合计90%的保守效率。原二维准静态结果仍适用：10 m保守拖线工况最小牵引安全系数约1.36；1.8 kg质量上限覆盖惰轮及薄壁罩的新增质量。

## 关闭提示验证

最终ID150装配以普通可写模式打开，共加载51个文档。逐一读取 `GetSaveFlag()`：51个文档均为 `False`，随后 `CloseAllDocuments(true)` 无保存关闭成功。另分别检查合盖装配、爆炸装配、七页分件图及整机总图；详细结果见 `printable_enclosure/CLEAN_CLOSE_*.txt`。

干涉审计工具改为只读打开，不再切换显示状态或强制重建，并在检查后主动关闭文档。正常打开查看再关闭不应再出现“文件已更改”的批量保存提示。

## 边界

本验证针对概念实体包络。实际全向轮滚子、齿形、弹簧腿、板卡孔位、紧固公差和线束弯曲半径仍须在采购实测后完成制造级复核。
