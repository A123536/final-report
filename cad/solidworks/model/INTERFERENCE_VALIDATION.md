# SOLIDWORKS 修订装配干涉与状态验证

## 修订原因

首版概念装配报告 246 处实体相交。除轴、轴承和紧固连接外，主要问题是设备舱被画成实心块、φ60全向轮被画成整圆盘、直接25T/40T传动使φ37齿轮箱侵入轮子包络，以及线束使用直线段穿过电机和板卡。

## 结构修订

- 全向轮改为φ26轮芯、φ18/φ8轮毂、6根薄辐条和12个滚子包络，整体接触包络仍为φ60×28 mm。
- 增加25T惰轮：25T电机齿轮—25T惰轮中心距25.0 mm，惰轮—40T轮轴齿轮中心距32.5 mm；电机轴距轮轴57.5 mm，总减速比仍为1.6。
- 惰轮使用φ6轴及686（6×13×5 mm）轴承包络；三根主轴统一使用619/8（8×19×6 mm）轴承包络。
- 设备舱改为70×60×20 mm开口薄壁罩，壁厚2 mm；板卡重新排布，RS-485旋转90°安装。
- 连杆双侧轨道移至Y=±43 mm；中心轴修正为φ8 mm；轴承、扭簧、限位片和40 mm快拔销分层布置。
- 电源线和信号线分别走Y=-37 mm和Y=+37 mm通道，在中心关节降低高度，并绕开前电机与主动轮后进入相机舱。

## 实体干涉检查

使用 SOLIDWORKS InterferenceDetectionManager，关闭“重合视为干涉”，检查全部实体组件。

| 管径姿态 | 报告项 | 非预期干涉 | 结果 |
|---:|---:|---:|---|
| 140 mm | 25 | 0 | 通过 |
| 150 mm | 25 | 0 | 通过 |
| 160 mm | 25 | 0 | 通过 |

最终25项均属于有意连接：

- 2项限位片与连杆轨道连接；
- 1项格兰头与外部拖线连接；
- 4项齿轮啮合包络；
- 2项快拔销与轨道/限位片连接；
- 2项电源线与格兰头/拖线入口连接；
- 12项相邻线束段端点连接；
- 2项线束进入相机舱。

滚子中心已修正到Y=±10 mm，8 mm宽滚子的总外廓严格位于±14 mm内；首轮约0.064 mm的管壁数值穿透已消除。140 mm工况下保险端子额外向罩壳法向内收1 mm后通过管壁检查。

最终新增的686惰轮轴承在150 mm实体模型中通过检查；其与惰轮、轨道的相对局部几何不随管径姿态变化。619/8包络由旧模型误用的8×22×7 mm缩小为真实的8×19×6 mm，因此不会缩小140/160 mm姿态的既有间隙。

## 受力与牵引模型复核

修订没有改变轮径、150 mm连杆轴距、弹簧参数、目标质量上限或总传动比。新增惰轮带来两次外啮合，仿真继续采用两次啮合合计90%的保守效率。原二维准静态结果仍适用：10 m保守拖线工况最小牵引安全系数约1.36；1.8 kg质量上限覆盖惰轮及薄壁罩的新增质量。

## 关闭提示验证

最终ID150装配以普通可写模式打开，共加载47个文档。逐一读取 `GetSaveFlag()`：47个文档均为 `False`，随后 `CloseAllDocuments(true)` 无保存关闭成功。

干涉审计工具改为只读打开，不再切换显示状态或强制重建，并在检查后主动关闭文档。正常打开查看再关闭不应再出现“文件已更改”的批量保存提示。

## 边界

本验证针对概念实体包络。实际全向轮滚子、齿形、弹簧腿、板卡孔位、紧固公差和线束弯曲半径仍须在采购实测后完成制造级复核。
