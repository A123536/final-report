# 中心关节角度传感器增补方案

日期：2026-11-04。

状态：最终整机的新增设计规划。计划安装一只绝对角度传感器，测量两根连杆之间的V型夹角；具体模块、安装支架、驱动程序和保护阈值尚待选型及实测。

本方案作为当前选定的2026-10-13模型基线的设计补充，不表示传感器已包含在原始ZIP、当前SOLIDWORKS装配或既有干涉验证中。当前模型版本及文件完整性以[仓库首页](../README.md)和[模型清单](../cad/solidworks/CURRENT_MODEL.json)为准。

## 1. 用途与采用理由

中心关节采用被动双扭簧压壁。电机编码器反映驱动电机的转动，FB反映电机负载，供电采样反映电源状态；这些信号不能直接给出两根连杆的相对夹角。

新增测角信号用于：

1. 装管后检查机构是否进入预期的展开姿态，例如锁销尚未拔出、铰链卡滞或装配不到位的排查。
2. 行走时记录夹角及其变化，结合转速、电流、供电和工作模式辅助诊断异常。
3. 验证管径—姿态关系，并为扭簧角度—转矩标定和压壁力模型提供角度输入。
4. 在上位机显示关节姿态，保存同步试验记录，支持后续设计比较。

角度传感器不参与20kHz PWM生成，不替代两路电机编码器，也不替代机械限位、锁销、驱动保护和可靠的扭簧安装。

## 2. 角度定义及理论参考

测量量记为β，定义为前后两根连杆之间的V型内夹角。传感器原始绝对角度不一定等于β，需要用软件偏置、方向和角度展开规则完成换算。

根据[当前机械方案](basic_mechanical_scheme.md)，参考值为：

| 管道内径 | 理论V型夹角β |
|---:|---:|
| 140mm | 约118.1° |
| 150mm | 约108.8° |
| 160mm | 约98.9° |

机械限位为90°～125°；装管时125°锁定是允许状态。上述角度为模型参考，实际阈值需考虑轮子实测尺寸、压缩、装配公差、间隙和标定误差。不能把98.9°～118.1°直接作为所有工作模式通用的故障窗口。

在已知管径、近似对称且轮子正常接触的条件下，可将实测夹角与模型比较。超出这些条件时，不能仅凭夹角反推准确管径或接触情况。

## 3. 能力边界

| 观测或推断 | 可用程度与限制 |
|---|---|
| 两连杆相对夹角 | 传感器直接测量，经标定得到β |
| 机构是否处于预期姿态 | 可结合工作模式和已知管径检查 |
| 压壁力估计 | 依赖真实扭簧曲线、预紧、几何和接触假设，需要测力验证 |
| 弹簧断裂或松脱 | 不能单独可靠判定，管壁可能仍把机构约束在同一角度 |
| 三轮接触、车轮打滑 | 不能单独证明，需要其他观测或试验 |
| 绕管轴侧翻角 | 不属于这个关节角度传感器的测量量 |
| 主动调节夹角/预紧力 | 当前没有相应执行机构，增加测量不产生主动调节能力 |

软件判断以多信号关联为依据。例如“电流增大、速度下降、角度明显变化”提示同时检查机构与管内几何；它不是已验证的单一故障判据。

## 4. 机械安装原则

中心被动轮、中心轴和V型铰链邻近布置，必须区分车轮转动与连杆相对转动。

```text
连杆A：固定传感器本体
           ↕ 测量绕关节轴线的相对转角
连杆B：固定参考件/磁铁
```

- 传感器本体与参考件分别随两根连杆运动，测量的是两者之间的相对角度。
- 不把参考件固定在自由旋转的中心轮上；中心轴若未与指定连杆固定，也不能直接当作该连杆的角度参考。
- 传感器支架只用于定位，不承担扭簧预紧或轮轴载荷，不削弱中心轴、轴承座、簧腿座和机械限位。
- 安装位要避让左右镜像扭簧、轴承、限位、锁销、线束及中心轮完整旋转包络。
- 磁式方案需要按器件手册确定磁铁类型、对中、间隙和固定方式，并检查附近钢轴、扭簧、电机及电流变化对读数的实际影响。
- 关节线束留足柔性弯曲段并设置应力释放，避免在90°～125°范围内拉扯接头。

下一次CAD细化需增加传感器、磁铁/参考件、支架和线束包络，并复查140/150/160mm姿态、装管锁定姿态及运动过程。现有模型不能据此视为已经完成该检查。

## 5. 选型及采购增补

优先考虑非接触式、上电即输出当前位置的绝对角度传感器。SPI型AS5048A可作为候选：厂家提供绝对磁角度测量、SPI和PWM接口。最终模块需结合安装空间、连接方式、3.3V逻辑和实测效果确定；高分辨率不等于相同数值的整机测量精度。

| 新增项目 | 数量 | 确认内容 |
|---|---:|---|
| 绝对角度传感器模块 | 1 | 候选AS5048A SPI型；确认真实芯片、供电、逻辑电平、尺寸和引脚 |
| 匹配磁铁/角度参考件 | 1 | 按最终传感器手册确定磁化方向、磁场和安装要求 |
| 传感器固定支架 | 1套 | 相对两连杆定位，尺寸待中心关节实测/CAD细化 |
| 固定件及防松件 | 1套 | 不改变扭簧安装与机械限位 |
| 短线束、接插件及应力释放 | 1套 | 3.3V、GND、SPI及片选，适应关节摆动 |

以上为新增采购需求，不代表已采购、已选定某款现货模块或已完成报价；不改写历史2026-10-28“87项采购清单”的项目数。

## 6. STM32与CubeMX接口预留

采用SPI2连接数字式绝对角度传感器，避免增加模拟ADC通道。以下是对整机电控规划的增补，仓库当前没有已集成该传感器的IOC或固件。

| STM32F411CEU6引脚 | CubeMX功能/建议标签 | 传感器连接 |
|---|---|---|
| PB12 | GPIO_Output，JOINT_CS | CSn，默认High，空闲不选中 |
| PB13 | SPI2_SCK，AF5 | SCK |
| PB14 | SPI2_MISO，AF5 | 传感器数据输出 |
| PB15 | SPI2_MOSI，AF5 | 传感器数据输入 |
| 3V3 | 供电，需核对模块电路 | 模块允许的3.3V入口 |
| GND | 共地 | GND |

SPI2选择主机、双线全双工、软件NSS；PB12用普通GPIO片选。时钟极性/相位、数据宽度、片选时序和读回流程依据最终器件及模块手册确定，不能仅按通用SPI示例照搬。角度采样数据量很小，首版不必增加SPI DMA或SPI中断；应使用有界超时，避免阻塞已有ADC处理。

该预留占用此前空闲的PB12～PB15；保留PA8/PA9电机PWM、PA0/PA1与PB6/PB7编码器、PA4～PA7模拟采样及USART2通信规划。最终生成IOC前复核所有复用。不要把候选I²C模块直接接到已承担编码器或方向控制的引脚上。

## 7. FreeRTOS接入

保持六个应用任务的划分，不为一只慢速关节传感器单独创建任务。角度采样周期先设为20ms（50Hz），最终按动作变化速度和实测任务负载确认。

| 任务 | 新增职责 |
|---|---|
| SensorTask | 每20ms读取角度及器件支持的状态/校验信息，换算β、滤波，发布带时间戳的有效数据 |
| SafetyTask | 检查数据过期、通信/器件异常、角度窗口和异常变化；结合工作模式与其他信号确认故障 |
| RobotStateTask | 区分装管、待机、行走、退出管道等阶段，选择相应允许条件和故障恢复流程 |
| CommTask | 将角度、有效标志及故障状态加入上位机遥测，不直接控制关节 |
| DiagnosticTask | 记录原始角度、标定角度、变化、通信异常和对应电流/转速/供电 |
| MotorControlTask | 保持双电机闭环；执行已确认的速度限制/停机许可，不增加关节位置控制环 |

建议在传感器快照中加入：

| 字段 | 含义 |
|---|---|
| joint_raw_angle_deg | 原始角度，保留用于排查标定问题 |
| joint_angle_deg | 标定后的V型内夹角β |
| joint_sample_tick | 最近一次有效采样的系统时间 |
| joint_valid | 本次数据是否通过通信、器件和换算检查 |
| joint_status | 器件/通信/磁场等错误状态，按实际器件支持定义 |

不能在读数失败时把角度强行填0或继续将旧值标作有效。角度跨0°/360°时先正确展开，再换算与滤波；不能把跨周误差当作关节突变。数据过期时间、异常确认次数和角速度阈值应可配置并经试验确定。

安全处理需避免以下误判：装管时125°锁定不自动判故障；瞬时噪声不直接触发紧急停机；传感器异常与机构异常分别记录。若正式运行把角度监测列为运动许可条件，数据持续无效时应按定义的故障策略停机并等待确认，不能静默失去该监测功能。

## 8. 标定、试验及交付检查

- [ ] 明确本体和参考件分别固定在哪根连杆，确认不读取中心轮转角。
- [ ] 用至少两个独立已知角度标定方向和偏置；避免只用原始电角度命名β。
- [ ] 检查90°～125°全行程的连续性、安装间隙和机械限位，记录重复定位误差。
- [ ] 在140、150、160mm管道中记录实际稳定角度，与理论参考比较后制定容差。
- [ ] 在电机停止、正反转、不同PWM和负载条件下验证读数稳定性与电磁影响。
- [ ] 断开传感器、模拟读数超时/错误，确认有效标志、日志和运动许可按定义处理。
- [ ] 在受控条件下测试装管锁定、正常行走、退出管道和机构受阻，避免混用状态阈值。
- [ ] 如需用角度估计压壁力，另用测力装置校核真实扭簧曲线和力学模型。
- [ ] 将实际模块、支架、磁铁和线束加入CAD，复核干涉、质量及中心关节空间。
- [ ] 固定最终型号、协议参数、标定方法、阈值和试验记录后再作为已验证整机功能发布。
